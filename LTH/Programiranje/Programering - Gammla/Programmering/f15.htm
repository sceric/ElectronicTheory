Lösningsförslag till uppgifterna vi löste under f15

Complex-uppgiften

Under föreläsningen kommenterade vi särskilt tre saker (punkt 2 är betydligt viktigare än punkt 1 och 3, som är av ringa betydelse).
  1. Vi har en privat konstruktor, dvs vi tillåter inte användaren att skapa nya komplexa tal med hjälp av c = new Complex(), istället måste hon anropa någon av våra "pseudo-konstruktorer" (newCartesian och newPolar). Dessa båda operationer är klassoperationer, eftersom de inte utförs på ett enskilt objekt utan på klassen i sin helhet.

  2. Vi försöker kapsla in attributen så väl som möjligt, även inom klassen. Som klassen är skriven nu är det bara operationerna på gul bakgrund som använder attributen direkt, överallt annars hämtas deras värde med hjälp av operationer. Poängen med detta är att klassen blir flexiblare, vi kan exempelvis byta tillståndsvariabler (till polär form, se nedan) utan att övriga operationer ändras.

  3. Vi låter operationerna setCartesian och setPolar returnera this. På så vis kan vi använda det värde som returneras direkt, exempelvis i newPolar som annars hade fått skrivas: 
        public static Complex newCartesian(double re, double im) {
        Complex c = new Complex();
        c.setCartesian(re,im);
        return c;
    }
Nedan har jag dessutom lagt till en operation String toString() som ger en strängrepresentation av talet. Alla klasser som har en sådan operation kan skrivas ut mycket enkelt, se exemplet nedan (i toString() har jag använt en av de formateringsklasser som finns i paketet java.text, dessa behöver ni inte lära er använda i kursen).

Det kan tyckas att lösningen är onödigt tillkrånglad, men dess avsikt är att visa ett antal tekniker som är användbara i större exempel (vi har i denna kurs inte tid att ge oss in i större exempel, så vi får använda principerna i enklare exempel). 

class Complex {

        private Complex() {
        }
    
        public static Complex newCartesian(double re, double im) {
            return new Complex().setCartesian(re,im);
        }
    
        public static Complex newPolar(double mag, double arg) {
            return new Complex().setPolar(mag,arg);
        }

// ================================================================
        
        private double
            re,
            im;
    
        public double getRe() {
            return this.re;
        }
        
        public double getIm() {
            return this.im;
        }
        
        public double getMagnitude() {
            return Math.sqrt(this.re*this.re + this.im*this.im);
        }
        
        public double getArgument() {
            return Math.atan2(this.im,this.re);
        }            
        
        public Complex setCartesian(double re, double im) {
            this.re = re;
            this.im = im;
            return this;
        }
        
        public Complex setPolar(double magnitude, double argument) {
            this.re = magnitude*Math.cos(argument);
            this.im = magnitude*Math.sin(argument);
            return this;
        }
// ================================================================
    
        public Complex add(Complex other) {
            return Complex.newCartesian(this.getRe() + other.getRe(),
                                        this.getIm() + other.getIm());
        }
        
        public Complex subtract(Complex other) {
            return Complex.newCartesian(this.getRe() - other.getRe(),
                                        this.getIm() - other.getIm());
        }
        
        public Complex multiply(Complex other) {
            return Complex.newPolar(this.getMagnitude()*other.getMagnitude(),
                                    this.getArgument() + other.getArgument());
        }
        
        public Complex divide(Complex other) {
            return Complex.newPolar(this.getMagnitude()/other.getMagnitude(),
                                    this.getArgument() - other.getArgument());
        }
    
        public Complex exp(double x) {
            return Complex.newPolar(Math.pow(this.getMagnitude(),x),
                                    x*this.getArgument());
        }
    
        public String toString() {
            final double eps = 0.0001;
            boolean
                hasRealPart = Math.abs(this.getRe()) > eps,
                hasImaginaryPart = Math.abs(this.getIm()) > eps;
            if (!(hasRealPart || hasImaginaryPart)) {
                return "0";
            } else {
                String re, im;
                if (hasRealPart) {
                    re = new DecimalFormat("0.0000;-0.0000").format(this.getRe());
                    if (hasImaginaryPart) {
                        im = new DecimalFormat(" + 0.0000i; - 0.0000i").format(this.getIm());
                    } else {
                        im = "";
                    }
                } else {
                    re = "";
                    im = new DecimalFormat("0.0000i;-0.0000i").format(this.getIm());
                }
                return re + im;
            }
        }
    }

BigBangTurtle-uppgiften

Uppgiften var att skriva ett program som lät ett godtyckligt antal sköldpaddor samtidigt göra slumpvandringar. I den första versionen lät vi sköldpaddorna hålla på tills någon lämnat fönstret, i den andra versionen bröt vi dessutom när två sköldpaddor befann sig mer än 70% av fönstrets bredd ifrån varandra.

Uppgiften skulle framförallt ge träning i att använda loopar, särskilt 'nästlade' loopar.

Vi har i lösningen två typer av loopar och nästling:

  • Ytterst har vi en while-sats och inne i den en for-sats. När vi skrev den första versionen av programmet (som bara höll på tills någon sköldpadda lämnat skärmen) hade vi: 
        while (!finished) {
      for (int i = 0; i < n; i++) {
            t[i].randomStep(1,5);
            if (!t[i].insideWindow()) {
                finished = true;
            }
        }
    }
    dvs vi lät samtliga sköldpaddor ta sitt sista steg innan vi bröt - den inre loopen går alltid ett bestämt antal varv.

  • I den andra versionen av programmet (se nedan) har vi inne i den yttre while-satsen två nästlade while-satser för att jämföra alla kombinationer av två sköldpaddor. Båda dessa senare while-satser skall brytas så snart vi hittat två sköldpaddor som är tillräckligt långt ifrån varandra.

    I programmet skrev vi dessa loopar med hjälp av while: 

        int i = 0;
    while (i < n-1 && !finished) {
        int j = i+1;
        while (j < n && !finished) {
            if (t[i].distanceTo(t[j]) > maxDistance) {
                finished = true;
            } else {
                j++;
            }
        }
        i++;
    }
    men man kan faktiskt skriva dem med hjälp av for-satser: 
        for (int i = 0; i < n-1 && !finished; i++) {
        for (int j = 0; j < n-1 && !finished; j++) {
            if (t[i].distanceTo(t[j]) > maxDistance) {
                finished = true;
            }
        }
    }
    Det är dock inte alla språk som kan bryta en for-loop på detta vis, och det är bra om ni i denna kurs tydligt markerar skillnaden mellan:

    • loopar som går ett bestämt antal varv (använd gärna for-sats för dessa), och

    • loopar som avbryts av ett villkor som vi inte kan bestämma innan loopen körts (använd helst while- eller do-while-satser för dessa).
För att ge övning i ärvning skapade vi olika subklasser till klassen Turtle, se programlistningen nedan. Vi har:
  • SmarterTurtle, som är den första utvidgningen av Turtle-klassen som vi gjorde under en föreläsning. Denna klass har operationer för att mäta avstånd mellan sköldpaddor, och dessutom en operation som testar om sköldpaddan befinner sig innanför sitt fönster.

  • TripmeterTurtle, som är en SmarterTurtle som kan räkna sina steg.

  • RandomTurtle, som är en TripmeterTurtle som kan ta slumpsteg.

  • BigBangTurtle, som är en RandomTurtle som skapas mitt i sitt fönster, med pennan nere.
Exemplet är, precis som det förra exemplet, draget till sin spets, men dess uppgift är bara att illustrera några vanliga programmeringstekniker. 

    import se.lth.cs.pt.io.*;
    import se.lth.cs.pt.random.*;
    import se.lth.cs.pt.window.*;
    import se.lth.cs.pt.turtle.*;
    
    public class f15 {
    
        public static void main(String[] args) {
            int windowSize = 500;
            int n = Keyboard.readInt("Antal sköldpaddor: ");
            SimpleWindow w = new SimpleWindow(windowSize,windowSize);
            BigBangTurtle[] t = new BigBangTurtle[n];
            for (int i = 0; i < n; i++) {
                t[i] = new BigBangTurtle(w);
            }
            boolean finished = false;
            double maxDistance = 0.70*windowSize;
            while (!finished) {
                for (int i = 0; i < n; i++) {
                    t[i].randomStep(1,5);
                    if (!t[i].insideWindow()) {
                        finished = true;
                    }
                }
                int i = 0;
                while (i < n-1 && !finished) {
                    int j = i+1;
                    while (j < n && !finished) {
                        if (t[i].distanceTo(t[j]) > maxDistance) {
                            finished = true;
                        } else {
                            j++;
                        }
                    }
                    i++;
                }
            }
            int sum = 0;
            for (int i = 0; i < n; i++) {
                sum += t[i].getNbrOfSteps();
            }
            System.out.println("Totalt antal steg: " + sum);
        }
    }
    
    class SmarterTurtle extends Turtle {
    
        public SmarterTurtle(SimpleWindow w, int x, int y) {
            super(w,x,y);
        }
        
        public boolean insideWindow() {
            return
                1 <= this.getX() && this.getX() <= this.getWindow().getWidth() &&
                1 <= this.getY() && this.getY() <= this.getWindow().getHeight();
        }
    
        public double distanceTo(Turtle other) {
            int dx = this.getX() - other.getX(),
                dy = this.getY() - other.getY();
            return Math.sqrt(dx*dx + dy*dy);
        }        
    }
    
    class TripmeterTurtle extends SmarterTurtle {
    
        private int
            nbrOfSteps;
    
        public TripmeterTurtle(SimpleWindow w, int x, int y) {
            super(w,x,y);
            this.reset();
        }
    
        public void reset() {
            this.nbrOfSteps = 0;
        }
    
        public int getNbrOfSteps() {
            return this.nbrOfSteps;
        }
    
        public void forward(int n) {
            super.forward(n);
            this.nbrOfSteps += n;
        }
    }
    
    class RandomTurtle extends TripmeterTurtle {
    
        protected RandomNumberGenerator rng;
        
        public RandomTurtle(SimpleWindow w, int x, int y) {
            super(w,x,y);
            this.rng = new RandomNumberGenerator();
        }
        
        public void randomStep(int minStep, int maxStep) {
            this.left(this.rng.randInt(0,359));
            this.forward(this.rng.randInt(minStep,maxStep));
        }
    }
    
    class BigBangTurtle extends RandomTurtle {
        
        public BigBangTurtle(SimpleWindow w) {
            super(w,w.getWidth()/2,w.getHeight()/2);
            this.penDown();
        }
    }
