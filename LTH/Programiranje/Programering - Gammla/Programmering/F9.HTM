Insättning i sorterad vektor

Om vi har en vektor v med n element kan vi lägga till ett nytt värde, value, sist i vektorn genom att skriva: 
    v[n] = value;
    n++;
(man kan även skriva v[n++] = value, dvs öka n samtidigt som vi använder den som index, vi kommer att diskutera detta lite senare i kursen.)

På detta vis kommer de inlagda elementen att hamna i kronologisk ordning, om vi vill ha dem sorterade måste vi vara lite mer omsorgsfulla när vi stoppar in elementen.

Om vi antar att vi har en vektor v med n sorterade element och vill lägga in ett nytt värde value i rätt ordning i vektorn kan vi resonera på föjande vis (vi förutsätter i det följande att det finns plats för ytterligare element i vektorn, dvs att n < v.length): 

    låt pos vara platsen efter det hittills sista elementet, det är
    den sista plats det nya elementet kan hamna på;

    så länge vi inte kommit till vektorns början, och elementet på
    platsen före pos är större än det nya värdet:

        flytta elementet som låg före pos till platsen pos, och
        minska pos ett steg;

    vi kan nu stoppa in det nya elementet i index pos;

    notera att antalet element i vektorn har ökat med 1;
Om vi skriver detta i Java får vi: 
    int value = ...det nya värdet...;
    int pos = n;    // sista element tidigare ligger i n-1
    while (pos > 0 && v[pos-1] > value) {
        v[pos] = v[pos-1];
        pos--;
    }
    v[pos] = value;
    n++;
Några saker som är värda att kommentera (under föreläsningen kommer vi att diskutera denna algoritm utförligt):
  • Vi låter pos få värdet n från början. Det finns ju tidigare n element i vektorn, från index 0 till n-1, så index n är platsen direkt efter det hittills sista elementet.

    Om det nya elementet visar sig vara större än de andra elementen i vektorn skall det läggas här.

  • I villkoret i while-satsen testar vi först att pos > 0, det gör vi för att inte få indexfel när vi hamnar först i vektorn. När pos == 0 har vi redan flyttat upp samtliga element i vektorn ett steg, och skall därför stoppa in det nya värdet först i vektorn.

    Precis som vid sökning är det alltså viktigt att testa pos innan vi ser vad som finns i v[pos-1] - om vi gör testen i omvänd ordning skulle vi få indexfel när vi hittar ett element som är det hittills minsta.

  • Vi kan efter while-satsen lägga value i index pos, oavsett om vi bröt för att vi hamnat på index 0, eller för att vi hittade ett värde som var mindre än value i index pos-1.

  • Det är viktigt att räkna upp n efteråt, annars skulle det nya elementet skrivas över när vi försökte lägga in ett nytt element.
Den inledande testen i while-villkoret, pos > 0, kan vi slippa om vi först i vektorn (på index 0) lägger en så kallad vaktpost. En vaktpost är ett värde som garanterat är större än eller mindre än alla andra värden i vektorn. I detta fall vill vi ha ett värde som är mindre än alla tänkbara värden, eftersom inget värde skall kunna hamna före vaktposten.

Vi kan få det största respektive minsta tänkbara heltalet genom att skriva Integer.MAX_VALUE eller Integer.MIN_VALUE. Med en vaktpost med värdet Integer.MIN_VALUE i index 0 skulle insättningen kunna skrivas: 

    v[0] = Integer.MIN_VALUE;  // detta görs en gång, inte vid
                               // varje insättning!
    // ...
    int value = ...det nya värdet...;
    int pos = n;
    while (v[pos-1] > value) {
        v[pos] = v[pos-1];
        pos--;
    }
    v[pos] = value;
    n++;
När vi denna gång kommer till pos == 1 kommer garanterat inte value att vara mindre än v[pos-1], som ju är vaktposten. Sökningen bryts och vi riskerar därför inte att få indexfel.

Sortering av vektorer

I många sammanhang är det fördelaktigt att hålla vektorer sorterade, inte minst om vi ofta skall söka i dem. Man har därför lagt ner mycken möda på att utveckla effektiva metoder för sortering, vi kommer idag att diskutera två enkla metoder, nämligen insättningssortering och bubbelsortering. Det kan tyckas onödigt att lära sig två olika sätt att göra samma sak, men meningen är att det skall ge er lite mer övning i att förstå algoritmer.

Insättningssortering

Med hjälp av insättningsalgoritmen ovan kan vi enkelt sortera en från början osorterad vektor genom att 'sortera in' element för element i vektorns början.

Vi börjar med att säga att det första elementet i vektorn kan betraktas som en sorterad delvektor med ett element. Därefter sorterar vi in element nummer två på, och får en delvektor med två element som är rätt sorterad. Vi fortsätter sedan på samma sätt genom hela vektorn.

En grov skiss skulle bli: 

    för varje element från det andra till det sista:

        sortera in elementet bland de första, sorterade, elementen
        i vektorn
och i Java får vi: 
    for (int i = 1; i < n; i++) {
        int value = v[i];
        int pos = i;
        while (pos > 0 && v[pos] > value) {
            v[pos] = v[pos-1];
            pos--;
        }
        v[pos] = value;
    }
Under föreläsningen kommer vi att gå igenom algoritmen i detalj.

Bubbelsortering (överkurs)

En annan populär sorteringsmetod är att låta element i vektorn "bubbla upp" genom vektorn, tills de hamnar på rätt plats. Det kan vi göra genom att upprepade gånger starta från det sista elementet i vektorn och jämföra med elementet före, om elementen är i fel ordning låter vi dem byta plats. Därefter jämför vi elementen med ett steg lägre index och fortsätter så tills vi kommer till vektorns första element. Denna första genomgång kommer att bubbla det minsta element till den första platsen. Därefter börjar vi en ny genomgång från det sista elementet, och fortsätter tills alla element bubblat upp till rätt plats. I varje steg kan vi bubbla ett steg mindre, eftersom vi redan bubblat upp vektorns minsta element. Om vi under någon genomgång från det sista elementet uppåt inte behöver byta plats på två element, så måste vektorn vara sorterad, och vi kan avbryta.

I Java-kod får vi något i stil med (man kan uttrycka den på många olika sätt): 

    int nbrOfSorted = 0;
    boolean haveSwapped;
    do {
        haveSwapped = false;
        for (int pos = n-1; pos > nbrOfSorted; pos--) {
            if (v[pos-1] > v[pos]) {
                int temp = v[pos-1];
                v[pos-1] = v[pos];
                v[pos] = temp;
                haveSwapped = true;
            }
        }
        nbrOfSorted++;
    } while (haveSwapped);

Om effektiv sortering

De båda sorteringsalgoritmer vi diskuterat ovan har fördelen att de är lätta att förstå och implementera, de är dock inte särskilt effektiva. Det är inga problem att sortera några 1 000 element med de givna metoderna, men så fort antalet element som skall sorteras blir lite större måste vi använda bättre metoder.

I våra fortsättningskurser kan ni lära er sorteringsmetoder som är väldigt mycket snabbare (så att ni kan sortera även 1 000 000-tals element på rimlig tid). Ni kommer även att lära er om datastrukturer som är väsentligt bättre än vektorer för att hålla reda på sorterade värden.
