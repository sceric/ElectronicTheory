Vektorer

Ofta vill man lagra många sammanhörande värden i sina program, under övning 2 skulle ni exempelvis beräkna medelvärde och standardavvikelse för ett antal tal som lästes in från tangentbordet. I uppgiften räckte det att läsa varje tal en gång och öka på två olika summor, ibland måste man dock spara samtliga värden för att bearbeta dem senare.

Fundera exempelvis på hur man skulle lösa följande två problem med bara vanliga variabler:

  1. Läs in 20 heltal och skriv ut dem i omvänd ordning.

  2. Läs in en följd av positiva heltal, avslutade med en 0:a, och skriv ut dem i omvänd ordning (här vet vi inte i förväg hur många tal vi skall läsa in och lagra).
Det finns i Java, och i alla andra vanliga programspråk, ett sätt att lagra flera värden i 'indexerade' variabler - de kallas vektorer. I en vektor kan vi lagra i princip hur många värden som helst, och nå dem med hjälp av index. I Java räknas index från 0 och uppåt.

I figuren nedan har vi en vektor (variabeln v refererar till vektorn) med 8 heltalselement, indexerade från 0 till 7.

Elementet med index 2 skrivs v[2] och har värdet 4. Om vi vill lagra värdet 16 i detta element skriver vi: 

    v[2] = 16;
Vi kan beräkna summan av samtliga element i vektorn v genom att skriva 
    int sum = 0;
    for (int i = 0; i < 8; i++) {
        sum += v[i];
    }
    System.out.println("Summan är " + sum);
Lägg märke till utformningen av for-satsen, tidigare har vi skrivit 
    for (int i = 1; i <= n; i++) {
        // ...
    }
för att gå n steg, men eftersom index i vektorer räknas från 0 skriver vi istället for-satser som skall gå igenom vektorer som 
    for (int i = 0; i < n; i++) {
        // här använder vi v[i]
    }

Att deklarera och skapa en vektor

Först ett klargörande: Som figuren ovan visar är v egentligen en referens till en vektor, vi kommer dock i det följande att tala om v som om den själv vore en vektor (först senare i kursen kommer vi att märka skillnaden).

Vi deklarerar en vektor genom att ange vilken typ elementen skall ha. För att deklarera en vektor med heltal, och en med referenser till Turtles skriver vi: 

    int[] v;
    Turtle[] t;
På detta vis skapar vi inga vektorer (och definitivt inga Turtles!). Istället har vi skapat två variabler som kan referera till vektorer, v kan referera till en vektor med heltal, och t till en vektor med referenser till Turtle.

Vektorerna skapar vi med new-satser, ungefär som vi skapar objekt. Skillnaden är att vi nu skapar en vektor med ett givet antal element, och att vi använder hakparenteser i new-anropet - några vanliga objekt skapas inte.

Att skapa två vektorer, en med 8 heltal, och en med 5 referenser till Turtle gör vi på följande sätt: 

    v = new int[8];    // skapar en vektor med 8 heltal
    t = new Turtle[5]; // skapar en vektor med 5 referenser till Turtles
Precis som när vi deklarerade referenser till vanliga objekt kan vi ge våra vektorvariabler startvärden genom att deklarera och tilldela på en gång (vi kommer ofta att använda denna form): 
    int[] v = new int[8];       
    Turtle[] t = new Turtle[5];
Vi får följande minnesutseende:

Till skillnad från vanliga lokala variabler får elementen i vektorerna automatiskt startvärden, elementen i en heltalsvektor får värdet 0 och elementen i en vektor med referenser blir automatiskt null.

Vi kan avgöra hur stor vektorn v är (om vi har glömt hur många element vi angav när vi skapade den!) genom att skriva v.length. Vi kan alltså alltid skriva ut samtliga element i en heltalsvektor v på följande sätt: 

    for (int i = 0; i < v.length; i++) {
        System.out.println(v[i]);
    }
Sköldpaddsvektorn t innehåller från början 5 null-referenser, vi har alltså inga sköldpaddor än. För att skapa en sköldpadda och låta det första vektorelementet referera till den skriver vi: 
    t[0] = new Turtle(w,100,100);
Vi får då följande innehåll i minnet:

Ett program som skapar en vektor med fem vektorelement, och därefter fem sköldpaddor skulle kunna skrivas: 

    SimpleWindow w = new SimpleWindow(600,300);
    Turtle[] t = new Turtle[5];       // Deklarerar och skapar en
                                      // vektor med 5 null-referenser
    for (int i = 0; i < t.length; i++) {
        t[i] = new Turtle(w,i*100 + 50, 200);
    }
Vi kommer att tala betydligt mer om vektorer under kommande veckor, bland annat om registrering, sökning, insättning och sortering.

Slumptal

Man kan i många sammanhang vilja använda slumptal, exempelvis för att simulera olika företeelser, eller för att skriva spelprogram.

Vi kan dra slumptal med hjälp av en slumptalsgenerator, i kursen har vi klassen RandomNumberGenerator som har följande specifikation.

Under föreläsningen kommer vi att diskutera hur man läser klasspecifikationer på detta format, försök förstå den så gott du kan.

Som exempel på hur man använder en slumptalsgenerator kan vi simulera ett tärningskast genom att skriva: 

    RandomNumberGenerator rng = new RandomNumberGenerator();
    int dieValue = rng.randInt(1,6);
Om vi vill ha ett reellt värde mellan 0 och 1 kan vi skriva 
    double x = rng.randDouble();
eller 
    double x = rng.randDouble(0,1);
