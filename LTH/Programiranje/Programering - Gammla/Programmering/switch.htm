switch-satsen

Det finns, förutom if-satsen, ett annat sätt att låta ett program välja väg, nämligen switch-satsen.

Den har följande utseende: 

    switch (uttryck) {
    case värde1:
       satser som utförs om uttryck har värdet värde1
       break;
    case värde2:
       satser som utförs om uttryck har värdet värde2
       break;
    case värde3:
       satser som utförs om uttryck har värdet värde3
       break;
    default:
       satser som utförs om uttryck inte har något av de
       värden som räknas upp ovan.
    }
Vi behöver inte använda default-alternativet.

Satsen ovan motsvarar if-konstruktionen 

    if (uttryck == värde1) {
       satser som utförs om uttryck har värdet värde1
    } else if (uttryck == värde2) {
       satser som utförs om uttryck har värdet värde2
    } else if (uttryck == värde3) {
       satser som utförs om uttryck har värdet värde3
    } else {
       satser som utförs om uttryck inte har något av de
       värden som räknas upp ovan.
    }
Om man inte skriver break kommer programmet att 'ramla igenom' nästa case-sats, vilket gör att satserna fram till nästa break utförs.

Exempel: För att skriva ut ett litet heltal med bokstäver kan vi skriva: 

    int nbr = Keyboard.readInt("Skriv ett tal: ");
    switch (nbr) {
    case 0:
        System.out.println("noll");
        break;
    case 1:
        System.out.println("ett");
        break;
    case 2:
        System.out.println("två");
        break;
    case 3:
        System.out.println("tre");
        break;
    case 4:
        System.out.println("fyra");
        break;
    default:
        System.out.println("ett tal större än 4");
    }
Observera att vi måste skriva break efter varje fall här, skulle vi ta bort break-satsen före case 4: skulle vi för värdet 3 få både utskriften tre och fyra.

Detta kan utnyttjas i vissa sammanhang, antag att vi vill skriva ut om en vokal är hård eller mjuk. Vi kan skriva: 

    System.out.print(ch + " är ");
    switch (ch) {
    case 'a':
    case 'o':
    case 'u':
    case 'å':
        System.out.print("en hård");
        break;
    case 'e':
    case 'i':
    case 'y':
    case 'ä':
    case 'ö':
        System.out.print("en mjuk");
        break;
    default:
        System.out.print("ingen");
    }
    System.out.println(" vokal");

    while (true) {
        terminal.displayText(...);

        ...
        if (bank.exists(accNo)) {
            switch (fcn) {
            case 1:
                ... satser som utförs om fcn == 1, dvs insättning ...

                break;
            case 3:
                ... satser som utförs om fcn == 3 dvs saldobesked...

        }
