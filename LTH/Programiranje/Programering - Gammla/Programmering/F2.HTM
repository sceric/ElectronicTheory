1. Introduktion till programmering

En kort genomgång av några viktiga begrepp

Under denna första föreläsning kommer vi att behandla några grundläggande begrepp, såsom
  • hur man lagrar värden i datorns minne
  • hur man gör enkla beräkningar
  • hur man läser in värden från användaren
  • hur man skriver ut värden
  • hur man får ett körbart program
Tanken är att ni efter att ha arbetat med detta avsnitt skall kunna skriva enkla program själva, för att få en känsla för principen med källkod och kompilering.

Det är inte säkert att vi hinner gå igenom allt under tisdagen, resten tar vi på måndag nästa vecka (då vi även kommer att diskutera objekt och referenser).

Under slutet av denna vecka kommer anteckningar till nästa veckas måndagsföreläsning att läggas ut.

Variabler och enkla typer

I datorns minne kan vi lagra värden, exempelvis
  • antal personer i ett register, antal sidor i en polygon etc (båda dessa värden är heltal)
  • en persons längd, mätt i meter, arean av en cirkel etc (dessa värden är reella tal)
  • enstaka bokstäver eller siffror (exempelvis 'a' eller '4')
För att lagra värden använder vi så kallade variabler. Varje variabel har en given typ (exempelvis heltal, reellt tal eller tecken) och den innehåller ett värde.

Variabler får ha namn som börjar på en bokstav och följs av bokstäver eller siffror. Exempel på tillåtna variabelnamn är a, area, distance, side1. Det är viktigt att variablerna har namn som förklarar vad de innehåller, om vi vill lagra basen och höjden i en triangel bör variablerna heta något i stil med base och height hellre än a och b (man använder i regel engelska variabelnamn). I Java skiljer man mellan små och stora bokstäver, så nbrOfSides och nbrofsides är inte samma variabel.

Alla variabler måste deklareras innan de används. Vid deklarationen talar man om vad variabeln heter och vilken typ den har.

De primitiva typer vi kommer att använda oss av mest i början av kursen är:

  • heltal, kallas i Java för int (efter engelskans integer),
  • reella tal, kallas i Java för double (efter engelskans double precision floating point number)
  • tecken, kallas i Java för char (efter engelskans character)
Man skiljer i Java (liksom i de flesta andra programspråk) mellan heltal och reella tal, heltal är exakta medan reella tal alltid är avrundade. Mer om detta senare.

Vi kan deklarera två heltalsvariabler, a och b, genom att skriva 

    int a;
    int b;
eller, enklare 
    int a,b;
Först skriver vi alltså vilken typ vi vill ha, sedan våra variabelnamn (avgränsade med kommateckan), och så avslutar vi deklarationen med ett semikolon.

Inläsning av värden från tangentbordet

Att göra utskrifter

I motsats till fallet med inläsning finns det i standard Java ett enkelt sätt att skriva ut i terminalfönstret. Man kan skriva
  • System.out.print("text att skriva ut");, eller
  • System.out.println("text att skriva ut");
Skillnaden mellan de båda är att man i det andra fallet bryter till en ny rad efter utskriften, ln i println kan alltså tolkas "print line".

Här är ett exempel: 

    System.out.print("Första utskriften.");
    System.out.print("Andra utskriften.");
ger utskriften 
    Första utskriften.Andra utskriften.
medan 
    System.out.println("Första utskriften.");
    System.out.println("Andra utskriften.");
ger 
    Första utskriften.
    Andra utskriften.
Om vi vill skriva ut värdet på variabeln area kan vi göra det genom att skriva 
    System.out.println(area);
eller, med förklarande text: 
    System.out.println("Arean är " + area);
Det andra exemplet kan även skrivas 
    System.out.print("Arean är ");
    System.out.println(area);
Vi kommer senare i kursen att se mer på hur man skriver ut på detta vis, vi kommer även (snart) att se ett alternativt sätt att skriva ut, med vars hjälp vi kan formattera utskrifterna bättre.

Att göra programkoden till ett fungerande program

Vi vet nu tillräckligt mycket för att skriva ett program som läser in basen och höjden i en triangel, och sedan skriver ut triangelns area.

De programrader vi behöver är 

    double base, height, area;
    base = Keyboard.readDouble("Ange triangelns bas: ");
    height = Keyboard.readDouble("Ange triangelns höjd: ");
    area = base*height/2;
    System.out.println("Triangelns area är " + area);
men för att få ett körbart program måste vi packa in raderna i den form alla Java-program skall ha.

Innan kursen är slut kommer ni att förstå (hoppas jag!) precis vad den allmäna formen egentligen betyder, men till dess får ni helt enkelt lära er den som ett 'mantra': 

    import ...eventuella hjälppaket...;

    public class ...programnamn... {
    
        public static void main(String[] args) {
            ...de egentliga programraderna...
        }
    }
där det är tre saker som ni skall fylla i:
  • Import av eventuella hjälppaket, om ni skall läsa från tangentbordet med hjälp av Keyboard-funktionerna måste ni importera paketet se.lth.cs.pt.io.Keyboard. Namnet ser avskräckande ut, men är egentligen logiskt, paketet är skrivet på institutionen (cs.lth.se) och det tillhör programmeringsteknik-kursen (pt). Paketnamnet skrivs baklänges, alltså se.lth.cs, och därefter pt.Keyboard.

  • Programnamnet, som bör vara ett namn som beskriver programmets uppgift. Programnamnet måste vara samma som namnet på källkodsfilen (den fil som innehåller programtexten). Enligt gängse konventioner skall programnamnet skrivas med stor begynnelsebokstav.

  • De egentliga programraderna infogas sedan efter public static void main(String[] args)-deklarationen.
I vårt exempel får vi 
    import se.lth.cs.pt.io.Keyboard;
    
    public class Area {
    
        public static void main(String[] args) {
            double base, height, area;
            base = Keyboard.readDouble("Ange triangelns bas: ");
            height = Keyboard.readDouble("Ange triangelns höjd: ");
            area = base*height/2;
            System.out.println("Triangelns area är " + area);
        }
    }
Denna text skall sparas i en vanlig textfil med namnet Area.java (filen måste alltså heta så).

För att nu datorn skall förstå programmet skall det kompileras till ett för datorn begripligt format. Det gör vi genom att i terminalfönstret skriva 

    javac Area.java
där javc betyder java compiler.

Om programmet är korrekt så skapar kompilatorn en ny fil som heter Area.class. Det är denna fil vi sedan kan köra.

Vi kör programmet genom att skriva 

    java Area
Observera att det inte går att skriva java Area.class, trots att det är filen Area.class som körs (man anger alltså filnamnstillägg (.java) när man kompilerar, men inte när man kör programmet).

När vi kör programmet får vi följande dialog (det fetstilta är det användaren matar in): 

    Ange triangelns bas: 4
    Ange triangelns höjd: 3.5
    Triangelns area är 7.0

Alternativ

Ibland måste programmet välja vad som skall göras beroende på något villkor. Antag till exempel att vi skall läsa ett tal och avgöra om det är större än 10, eller bestämma vilket av två inlästa tal som är störst. I Java använder man if-satsen för att göra olika saker beroende på ett villkor.

Vi har två olika slags if-satser:

  • I den ena varianten gör vi något bara då ett villkor är uppfyllt: 
        if (a > 10) {
        System.out.println("a är större än 10");
    }
    Om a är större än 10 skrivs texten ut, annars händer ingenting.

  • I det andra fallet gör vi något även då villkoret inte är uppfyllt: 
        if (a > 10) {
        System.out.println("a är större än 10");
    } else {
        System.out.println("a är inte större än 10");
    }
    I detta fall skrivs, precis som ovan, texten a är större än 10 ut om a är större än 10, men nu skrivs även en text ut ifall a inte är större än 10.
De allmäna formerna är 
    if (villkor) {
        ...satser som utförs om villkoret är uppfyllt...
    }
respektive 
    if (villkor) {
        ...satser som utförs om villkoret är uppfyllt...
    } else {
        ...satser som utförs om villkoret inte är uppfyllt...
    }
Lägg märke till klamrarna, { och }, de används för att avgränsa de satser som skall utföras i respektive fall. Klamrarna behövs egentligen inte om bara en sats skall utföras, men enligt Javas 'kodstandard' bör man sätta ut klamrarna även då. I kursen kommer vi att följa denna konvention och tvinga er att alltid sätta ut klamrarna! Genom att alltid skriva ut klamrarna slipper man många onödiga fel och många timmars onödig felsökning.

För att programmen skall bli lättare att läsa skall de satser som står innanför klamrarna dras in fyra mellanslag (som ovan), även detta anges i Javas kodstandard och vi kommer att begära att ni gör det. Lyckligtvis kan man få emacs (den texteditor ni använder) att automatiskt dra in raderna på rätt sätt.

Ingen människa blir lycklig av att läsa if-satsen ovan som: 

      if (a > 10)System.out.println("a är större än 10"); else{
    System.out.println("a är inte större än 10");}
även om kompilatorn accepterar den.

Villkoren kan se ut på olika sätt, till en början kommer vi att använda följande:

  • test av likhet: vi kan se om två heltal eller tecken, a och b, är lika med hjälp av villkoret a == b (observera att vi har två likhetstecken, ett likhetstecken används vid tilldelning).

    Denna jämförelse är meningslös för reella tal eftersom de är avrundade och vi därför med stor sannolikhet får problem med avrundningsfel.

  • test av olikhet: a != b

    (även denna jämförelse är meningslös för reella tal)

  • test om ett värde är mindre än ett annat: a < b

  • test om ett värde är mindre än eller lika med ett annat: a <= b

  • test om ett värde är större än ett annat: a > b

  • test om ett värde är större än eller lika med ett annat: a >= b
Satserna innanför klamrarna kan vara vilka satser som helst, exempelvis nya if-satser. Det är alltså tillåtet att skriva: 
    if (a > b) {
        if (c > d) {
            ...hit kommer vi bara om både a > b och c > d...
        }
    }
Dessutom är det vanligt att man efter else vill testa ett nytt villkor, enligt rekommendationen att sätta ut klamrar borde man då egentligen skriva 
    if (a > b) {
        ...
    } else {
        if (c > d) {
            ...hit kommer vi bara om c > d och dessutom inte a > b...
        } else {
            ...hit kommer vi om varken a > b eller c > d...
        }
    }
men man skriver istället hellre (och det är OK enligt kodkonventionen!): 
    if (a > b) {
        ...
    } else if (c > d) {
        ...hit kommer vi bara om c > d och dessutom inte a > b...
    } else {
        ...hit kommer vi om varken a > b eller c > d...
    }
Vi kan använda denna konstruktion exempelvis för att avgöra om ett tal är positivt, negativt eller noll: 
    int a;
    a = Keyboard.readInt("a: ");
    if (a > 0) {
        System.out.println("a är positivt");
    } else if (a < 0) {
        System.out.println("a är negativt");
    } else {
        System.out.println("a har värdet noll");
    }
I det sista fallet är a varken större än eller mindre än noll, det måste därför vara noll. Se även den sista kontrolluppgiften nedan.

Upprepning

Om vi i ett program skall läsa in och beräkna medelvärdet av 100 tal skulle vi få en väldigt klumpig lösning om det inte fanns något enkelt sätt att upprepa satser. Än värre vore det om vi skulle läsa en följd av positiva tal avslutade med en 0:a, eftersom vi då inte i förhand vet hur många tal som skall läsas in.

Lyckligtvis finns det i Java sätt att upprepa satser (det kallas även för iteration), vi kommer här att behandla de två vanligaste varianterna:

  • for-satsen, och
  • while-satsen.

for-satsen

Den enklaste formen av for-sats ser ut så här: 
    int i;
    for (i = 1; i <= 100; i = i + 1) {
        ...dessa satser upprepas 100 gånger...
    }
där parentesen innehåller tre delar:
  • en initieringsdel, som utförs före första varvet,
  • en villkorsdel, som innehåller ett villkor som måste vara uppfyllt för att vi skall utföra satserna innanför klamrarna, och
  • en uppräkningsdel, som utförs efter varje varv, precis innan vi testar villkorsdelen nästa gång.
Formellt skriver man alltså: 
    for (initiering; villkor; uppdatering) {
        ...satser...
    }
Precis som i fallet med if-satsen bör man använda klamrarna runt de satser som skall utföras.

Ett program som läser in och beräknar medelvärdet av 100 tal skulle kunna skrivas: 

    int i;
    double nbr, sum, average;
    sum = 0;
    for (int i = 1; i <= 100; i = i+1) {
        nbr = Keyboard.readDouble();
        sum = sum + nbr;
    }
    average = sum/100;
    System.out.println("Medelvärdet är " + average);
Lägg märke till att vi måste nollställa variabeln sum före for-loopen (de andra variablerna får värden innan de används första gången).

Denna form av for-satsen är bekväm när vi i förväg vet hur många gånger vi vill upprepa någonting.

while-satsen

Om vi inte vet i förväg hur många gånger vi skall upprepa våra satser är det enklare att använda while-satsen. Den har den allmäna formen: 
    while (...villkor...) {
        ...dessa satser upprepas så länge villkoret är uppfyllt...
    }
while-satsen illustreras nog bäst med ett exempel: Vi vill läsa in en följd av positiva heltal, avslutade med ett negativt tal, och beräkna deras summa: 
    int nbr, sum;
    sum = 0;
    nbr = Keyboard.readInt();
    while (nbr >= 0) {
        sum = sum + nbr;
        nbr = Keyboard.readInt();
    }
    System.out.println("Summan är " + sum);
Vi börjar med att nollställa summan, därefter låter vi variabeln nbr få värdet av det först inlästa talet. Om detta tal är större än 0 ökar vi summan med talet och låter nbr få värdet av nästa inlästa tal. Detta upprepas tills det inlästa talet inte längre är större än 0.

En vanlig missuppfattning är att while-satsen bryts så fort villkoret inte är uppfyllt, men den bryts inte förrän alla satser inne i loopen är färdiga och villkoret testas på nytt. I exemplet nedan kommer alltså den sista utskriften inne i while-loopen att skrivas ut: 

    int value;
    value = 1;
    while (value > 0) {
        value = -1;
        System.out.println("Loopen bryts inte förrän efter denna utskrift");
    }
Se även den sista kontrolluppgiften nedan.
