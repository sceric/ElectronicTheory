Klassen Account
import se.lth.cs.pt.ovn.misc.Account;

Konstruktorer
Account(int accNo, String owner)
Skapar ett nytt konto.
Parametrar:
accNo: kontonummer.
owner: namn på ägaren av kontot.
Operationer
int getAccNo()
Ger kontonumret.
Returnerar kontonumret.
String getOwner()
Ger namnet på ägaren.
Returnerar ägarens namn.
void deposit(int amount)
Sätter in ett belopp.
Parametrar:
beloppet: som skall sättas in, negativt belopp motsvarar uttag.
int getBalance()
Ger saldot.
Returnerar saldot.
