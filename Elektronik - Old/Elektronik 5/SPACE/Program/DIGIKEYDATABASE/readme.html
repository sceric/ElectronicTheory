Release 9.2 Capture CIS Starter Database
Release Notes

September, 2001

This database contains information for more than 66,000 parts found in the Digi-Key catalog (http:\\www.digikey.com). Roughly 45,000 of these Digi-Key parts have associated Orcad schematic graphical representations. Using this database, you can explore, query, filter, and place Digi-Key parts directly onto your Release 9.2 (or later version) Capture CIS schematic page.

Although this database is supplied in Microsoft Access Database format (DIGIKEY.MDB), you can transition the data into any database format you and your company require. When used with a database application less robust than Access, such a large database of parts will decrease CIS performance. For this reason, we recommend that you transition the database to SQL Server or an equivalent client/server database. If you must transition to a less robust database application, reduce the number of parts in the database by including only those that meet your immediate design requirements (your set of "preferred parts").

This database is intended for Release 9.2 (or later version) Capture CIS users because the schematic parts associated in the database are only available from the new schematic parts libraries supplied on the Release 9.2 (or later version) CD. You will also need to download DIGIKEYLIBRARIES.ZIP from the CIS Starter Database download web page to complete the set of libraries required to support this database.

In addition to the starter database, the .ZIP file contains a Capture CIS Release 9.2 configuration file DIGIKEY.DBC. When prompted, it is important that you save the configuration file in the new format for use with your version of Capture CIS. If you use the database with another version of Capture CIS, you need to save the configuration file again for that version of Capture CIS.

For the configuration file and the database to operate as intended, you need to use the ODBC Access driver to create a data source named Digikey. This name is case-sensitive and needs to be created before opening the configuration file.

For information about creating the Data Source Name, see Setting up the ODBC data source in the OrCAD Component Information System User's Guide.
